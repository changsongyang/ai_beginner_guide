# 第六章 大语言模型详解

> 深入理解 ChatGPT、Claude 等大语言模型的技术原理

---

大语言模型（Large Language Models，LLM）是当今 AI 最热门的技术方向。ChatGPT 的发布引爆了全球对 AI 的关注，让 AI 从专业领域走进了普通公众的生活。本章将深入解析大语言模型的技术原理，帮助读者理解这些令人惊叹的系统是如何工作的。

## 本章内容

- **6.1 从 RNN 到 Transformer**：回顾语言模型的技术演进
- **6.2 大语言模型的工作原理**：理解 LLM 如何理解和生成文本
- **6.2b Transformer 与注意力机制**：深入理解 Transformer 架构的核心机制
- **6.3 预训练与微调**：掌握 LLM 的训练范式
- **6.4 主流大语言模型介绍**：了解 GPT、Claude、Gemini 等主流模型
- **6.5 大模型的部署与推理**：让大模型在云端跑起来的基础原理

## 拓展章节

学完本章基础内容后，以下三个拓展章节将带你深入 LLM 技术的前沿方向：

- **拓展A 推理模型与推理计算**：探索 OpenAI o1、DeepSeek-R1 等新一代推理增强模型，理解"慢思考"如何让 AI 解决更复杂的问题
- **拓展B 超越 Transformer：SSM 混合架构**：了解 Mamba 等状态空间模型如何突破 Transformer 的二次复杂度瓶颈，实现更高效的长上下文处理
- **拓展C DeepSeek 深度解析**：深入解析这家中国 AI 创业公司的技术创新（MLA、MoE），以及 DeepSeek-R1 如何成为推理模型领域的黑马

> 这些拓展章节属于进阶内容，零基础读者可以在完成主线章节后再回来阅读。
