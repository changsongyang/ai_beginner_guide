## 14.1 什么是智能体？

本节用通俗易懂的方式介绍智能体的核心概念，并通过生活实例说明它与传统聊天机器人的本质区别。

> 💡 关于智能体的完整介绍，请参阅《智能体 AI 权威指南》。

### 14.1.1 核心概念

智能体是 **能够自主规划、调用工具、观察结果并持续改进的 AI 系统**。

简单来说，它具备以下关键特征：
- **感知能力**：理解用户需求和环境变化
- **规划能力**：把大目标拆解成可执行的小步骤
- **行动能力**：通过工具（API、浏览器、代码等）与世界交互
- **记忆能力**：学习历史经验，改进后续决策

在实际应用中，工具接入越来越强调 **标准协议**（例如 MCP）。好处是：一个智能体框架接好的工具，更容易迁移到另一个框架，降低重复开发成本。

### 14.1.2 为什么智能体与聊天机器人不同？

目前的 Chatbot 有两个大问题：
1. **幻觉**：不知道的瞎编，无法调用工具验证。
2. **行动力缺失**：只能输出文字，无法改变现实世界。

智能体解决了这两个问题——它能看、能想、能做。近年的智能体不再只是单打独斗，而更像是 **“团队作业”**。通过多智能体协作（Multi-Agent Collaboration），它们能处理更复杂的任务。

不少行业领袖都提出过类似判断：AI 智能体可能会显著改变软件形态，未来用户更像是在“交代任务”，而不是逐个操作 App。

### 14.1.3 现实案例：旅行规划

**场景：旅行代理智能体**

你说：“帮我订下周去三亚的机票和酒店，预算 5000。”

**普通 Chatbot 的回复**：
“你可以去携程或去哪儿网看看...”

**智能体的实际行动**：
1. 调用日历 API 确认下周具体日期
2. 调用天气 API 查看三亚天气
3. 调用机票搜索 API，发现直飞价格 3200，转机价格 1800
4. 调用酒店 API，列出亚龙湾的选项
5. 根据预算约束（5000）选择转机方案 + 3 星酒店
6. 反馈给你：“已找到方案：周三上午吉祥航空转机，酒店亚龙湾海景，总价 4800。需要我下单吗？”

**关键差异**：智能体不只是给建议，而是 **主动调用工具、比较选项、独立决策**。
